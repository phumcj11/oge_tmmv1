Ofero TMM System — ระบบบริหารงาน Trade Marketing
เวอร์ชัน 1.0 · ครอบคลุม SOP 001–005
สำหรับผู้ใช้งานทุกบทบาท (TMM / Approver / Area / Accounting / Staff)

1. เริ่มต้นใช้งาน

1.1 เข้าสู่ระบบ

  1. เปิดเว็บเบราว์เซอร์ไปที่ที่อยู่ของระบบ (เช่น https://oge.k-mkt.com)
  2. กรอก ชื่อผู้ใช้ และ รหัสผ่าน ที่ผู้ดูแลระบบให้มา แล้วกด "เข้าสู่ระบบ"
  3. ผู้ดูแลระบบเริ่มต้นคือ admin — ควรเปลี่ยนรหัสผ่านหลังเข้าใช้ครั้งแรก
ระบบรองรับมือถือ — พนักงานหน้างาน (staff) เข้าผ่านมือถือจะเห็นเฉพาะ "งานของฉัน"

1.2 บทบาทผู้ใช้ (Roles) และสิทธิ์

บทบาททำอะไรได้
adminทุกอย่าง + จัดการผู้ใช้/ระบบ
tmm (Trade Marketing Manager)สร้าง/แก้แคมเปญ, ให้คะแนนร้าน, ล็อกเวอร์ชัน, ตั้ง Readiness, บันทึกผลประเมิน
approver (RGM)อนุมัติแคมเปญ/งบ, อนุมัติรอบคะแนน, Override Tier, อนุมัติผล Review

1.3 แท็บเมนู

แถบเมนูด้านบนแบ่งเป็น 2 กลุ่ม:

งานประจำวัน: DashboardDealerโครงการEventPOSMSell-outมาตรฐานร้าน

วงจร Campaign (SOP): 🎯 Campaign📊 จัดลำดับ⚙️ Execution📈 ประเมินผล🧭 TM Board

2. วงจรงานหลัก (ภาพรวมการใช้งาน)

จัดลำดับร้าน → สร้าง Campaign + Brief → ผ่าน Readiness Gate → ขออนุมัติ → ล็อก Version → Execution หน้างาน → ประเมินผล ROI → ปิดงาน → เรียนรู้สู่รอบถัดไป

ทุกอย่างเชื่อมกันด้วยรหัส Campaign ID · Version · Dealer ID · Action ID ทำให้ติดตามย้อนหลังได้ตลอดเส้นทาง

3. จัดลำดับร้าน (Dealer Priority)

ใช้จัดอันดับความสำคัญของร้านด้วยเกณฑ์เดียวกันทั้งประเทศ → ได้ Tier (A/B/C/D/Hold)

ขั้นตอน (TMM)

  1. ไปที่แท็บ 📊 จัดลำดับ → กด ➕ รอบใหม่ ตั้งชื่อรอบ เช่น 2026-Q4
  2. กด ➕ ให้คะแนนร้าน → เลือกร้าน + ให้คะแนน 6 หมวด (เต็ม 100): ยอดขาย 25 · ศักยภาพ 20 · โอกาส 15 · Stock 15 · Execution 15 · เครดิต/บริการ 10
  3. ระบบคำนวณ Tier ให้อัตโนมัติ: A ≥ 80 · B ≥ 65 · C ≥ 50 · D < 50
  4. ถ้าร้านมีความเสี่ยง ให้ติ๊ก Critical Gate = Hold → Tier จะเป็น Hold แม้คะแนนสูง

อนุมัติ (Approver)

  1. กด ✅ อนุมัติรอบ → ระบบล็อกคะแนน + อัปเดต Tier เข้าทะเบียนร้านให้อัตโนมัติ
  2. หากต้องปรับ Tier ด้วยเหตุผลเชิงกลยุทธ์ → ใช้ Override (ต้องระบุเหตุผล + วันหมดอายุ)
สำคัญ: ให้คะแนนไม่ครบ 6 หมวด = "Missing Data" (ไม่จัด Tier) — ห้ามเดา/ใส่ศูนย์ · คะแนนแต่ละรอบเก็บแยกเป็นประวัติ ไม่เขียนทับรอบเดิม

4. Campaign — สร้าง อนุมัติ ล็อก

4.1 สร้างแคมเปญ (TMM)

  1. แท็บ 🎯 Campaign → กด ➕ สร้างแคมเปญ → กรอกชื่อ/วัตถุประสงค์/ประเภท/ภูมิภาค/งบแผน
  2. ระบบสร้าง Campaign ID อัตโนมัติ (เช่น CMP-2026-001) สถานะเริ่มต้น = Draft
  3. คลิกที่แคมเปญเพื่อเปิดรายละเอียด — กรอก Brief และตั้งค่าต่างๆ

4.2 Readiness Gate (7 ข้อ)

ในหน้ารายละเอียดแคมเปญ ตั้งสถานะความพร้อม 7 ด้าน: Brief · Dealer · Budget · Stock · POSM · Execution · Risk
แต่ละด้านเลือก Ready / Pending / Not Ready → ระบบสรุปเป็น Overall

บล็อกจริง: ถ้ายังไม่ Ready ครบ จะ ส่งขออนุมัติไม่ได้ (เว้นมี Exception ที่อนุมัติ)

4.3 ขออนุมัติ → อนุมัติ → ล็อก

  1. TMM: กด "ส่งขออนุมัติ" (สถานะ → Pending Approval)
  2. Approver: เปิดแคมเปญ → กด "✅ อนุมัติ" หรือ "✕ ปฏิเสธ"
  3. TMM: เมื่ออนุมัติแล้ว กด "🔒 ล็อก Version"
Version Lock: แคมเปญที่ล็อกแล้ว แก้สาระสำคัญไม่ได้ — ต้องกด "✎ Change Request" เพื่อสร้างเวอร์ชันใหม่ (ระบุเหตุผล) แล้วเริ่มขออนุมัติใหม่
ทุกการเปลี่ยนสถานะ/อนุมัติ ถูกบันทึกใน ประวัติ (Audit) ในหน้ารายละเอียด — ใคร/เมื่อ/ค่าเดิม/ใหม่

5. Execution — หน้างาน

แท็บ ⚙️ Execution → เลือกแคมเปญ จะเห็น 5 การ์ด:

การ์ดใช้ทำอะไร
🚦 Opening Readinessตรวจก่อนเปิดร้าน (6 จุด) → ระบบสรุปเป็น Go / Hold
📈 Live KPIบันทึกยอดระหว่างวัน (เป้า vs จริง → On Pace / Below Pace)
🚨 Incidentแจ้งเหตุ — เลือก Level (Critical/High/Medium/Low) ระบบกำหนด SLA + ผู้ที่ต้องแจ้ง ให้อัตโนมัติ · กด "จัดการ" เพื่อปิดเหตุ
💰 Expenseบันทึกค่าใช้จ่าย — จ่ายจริงต้องอ้าง Approval ID · ฝ่ายบัญชีกด "ยืนยัน"
📋 Daily Closeปิดยอดประจำวัน (ติ๊กครบ + ไม่มี issue ค้าง → Complete)

6. ประเมินผล (Post-Campaign)

แท็บ 📈 ประเมินผล → เลือกแคมเปญ จะเห็น 6 การ์ด:

การ์ดใช้ทำอะไร
💵 ROIกรอก Baseline/Actual units, Contribution/unit, งบ, จ่ายจริง → ระบบคำนวณ ROI แบบ incremental
🔻 FunnelFootfall → Lead → Test → Sale (ข้อมูลขาดแสดงว่าง ไม่ใช่ 0)
⚖️ Dealer Comparisonเทียบร้านหลายมิติ → ข้อมูลไม่ครบ = "Insufficient Data"
📝 Review & Decisionสรุป + ตัดสินใจ: Repeat / Revise / Stop / Test Further / Hold (Approver อนุมัติ)
🛠️ Corrective Actionsงานแก้ไข — มี Owner/กำหนดเสร็จ/สถานะ (Open→Closed)
🏁 Closureติ๊ก 6 gate ให้ครบ → ปิดแคมเปญ (สถานะ Closed)
ROI สถานะ: Calculated = คำนวณได้ + บัญชียืนยัน · Directional = คำนวณได้แต่บัญชียังไม่ยืนยัน · Not Calculated = ข้อมูลไม่พอ (ขาด baseline หรือจ่ายจริง=0) — ระบบไม่เดา ROI

7. TM Control Board

แท็บ 🧭 TM Board = ศูนย์ควบคุม รวมทุกอย่างที่ต้องจัดการในหน้าเดียว:

  • แคมเปญตามสถานะ · จำนวน รออนุมัติ · ยังไม่ผ่าน Readiness · ปิดแล้ว
  • Incident เปิดค้าง (เน้น Critical/High) · SLA เกิน
  • Corrective Action เกินกำหนด
  • สรุป ROI · งบแผน vs จ่ายจริง · Tier distribution
  • รายการที่ต้องจัดการ: รออนุมัติ / Incident ค้าง / Action เกินกำหนด
เปิด TM Board ทุกเช้าเพื่อเห็นว่าวันนี้ต้องจัดการอะไรบ้าง

8. โมดูลงานประจำวัน (โดยย่อ)

แท็บใช้ทำอะไร
📊 Dashboardภาพรวมยอดขาย/กำไร/ค้างชำระ ตามรุ่น·ภาค·เดือน + แผนที่
🏪 Dealerทะเบียนร้าน · แผนที่ · AI Insights · Dealer 360° (ดู/แก้ข้อมูลร้านรายร้าน)
📁 โครงการจัดกลุ่มกิจกรรมเป็นโครงการ + สรุปงบ/KPI รวม
🎪 Eventกิจกรรมหน้าร้าน (ตาราง/ปฏิทิน/Gantt/Kanban) + แนบรูป + เป้า vs ผล
📦 POSMคลังสื่อ เบิก-คืน + แจ้งเตือนของใกล้หมด
📈 Sell-outบันทึกยอดขายออก/สต็อก รายเดือน·ร้าน·รุ่น
🏬 มาตรฐานร้านประเมินร้าน checklist 7 ข้อ → % ความพร้อม + funnel

นำเข้าข้อมูลจาก Excel (admin)

ที่แท็บ Dealer / Sell-out มีปุ่ม ⬆ นำเข้า Excel → เลือกชนิด → ดาวน์โหลด template → อัปโหลดไฟล์ → ดูตัวอย่าง (preview) ว่าจะเพิ่ม/อัปเดตกี่แถว → กด "ยืนยันนำเข้า"

9. กฎสำคัญที่ต้องรู้

  1. ข้อมูลขาด ≠ ศูนย์ — ให้ปล่อยว่าง/ใช้สถานะ Missing ห้ามใส่ 0 มั่ว
  2. ต้องอนุมัติก่อนทำ — ห้าม launch/ก่อค่าใช้จ่ายจากแคมเปญที่ยังไม่อนุมัติ
  3. ล็อกแล้วแก้ไม่ได้ — ต้อง Change Request → เวอร์ชันใหม่
  4. ROI ต้องผ่านบัญชี — จึงจะเป็น "Calculated"; ไม่พอข้อมูล = Not Calculated
  5. เทียบร้านหลายมิติ — ห้ามตัดสินจากยอดขายค่าเดียว
  6. ทุกการอนุมัติ/เปลี่ยนสถานะสำคัญมีบันทึก (Audit) — ตรวจย้อนได้เสมอ
  7. เห็นเฉพาะพื้นที่ของตน — ผู้ใช้ระดับ Area เห็นเฉพาะ region ที่รับผิดชอบ

10. คำถามพบบ่อย

ปัญหาวิธีแก้
กด "ส่งขออนุมัติ" ไม่ได้ตรวจ Readiness Gate ให้ Ready ครบ 7 ข้อก่อน
แก้แคมเปญไม่ได้ (409)แคมเปญถูกล็อกแล้ว → ใช้ "Change Request" สร้างเวอร์ชันใหม่
ใส่คะแนนร้านไม่ได้รอบประเมินถูกอนุมัติ (ล็อก) แล้ว → สร้างรอบใหม่
ROI ขึ้น "Not Calculated"ข้อมูลไม่ครบ (ขาด baseline/contribution) หรือจ่ายจริง = 0
ไม่เห็นบางเมนู/ปุ่มเป็นเรื่องสิทธิ์ตามบทบาท (role) — ติดต่อผู้ดูแลระบบ
หน้าเว็บค้าง/เพี้ยนบนมือถือล้าง cache หรือเปิดแท็บส่วนตัว (Private) แล้วเข้าใหม่
